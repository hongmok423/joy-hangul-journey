# 조이의 한글 여행 🐰🗺️

만 6세 조이를 위한 26걸음 한글 학습 프로그램 — https://hongmok423.github.io/joy-hangul-journey/

언어학(한글 제자 원리·음절 구조) · 유아교육학(음운 인식 → 해독 → 유창성, 간격 반복) · 유아 디자인(색 약속, 음성 안내, 큰 터치) 관점으로 설계했습니다.

## 26걸음 과정

| 마을 | 걸음 | 핵심 |
|---|---|---|
| 🌲 소리 숲 | 1–2 | 손뼉으로 음절 세기, 첫소리(첫음절) 친구 찾기 |
| ☁️ 모음 하늘 | 3–5 | 천(·)·지(ㅡ)·인(ㅣ) → ㅣㅡ, ㅏㅓ, ㅗㅜ |
| 🏡 자음 마을 | 6–8 | 발음 기관 상형: ㄱㄴ(혀), ㅁ(입), ㅅ(이), ㅇ(목구멍·자리 지킴이) |
| 🧱 글자 블록 공방 | 9–10 | 키다리 모음은 오른쪽, 납작이 모음은 아래 / 첫 낱말 |
| 🌳 자음 가족 숲 | 11–14 | 가획: ㄱ→ㅋ, ㄴ→ㄷ→ㅌ(+ㄹ), ㅁ→ㅂ→ㅍ, ㅅ→ㅈ→ㅊ, ㅇ→ㅎ / 내 이름 "조이" |
| ⛰️ 점 하나 더 언덕 | 15–16 | ㅑㅕㅛㅠ(이+모음), ㅐㅔ(소리 같음 → 낱말로 기억) |
| 🎠 낱말 놀이터 | 17–18 | 2·3음절 낱말 읽기, 낱말 만들기 |
| 🏘️ 받침 마을 | 19–21 | ㅇㄴㅁ → ㄹ → ㄱㅂ(ㅅ=ㄷ소리) |
| 🌉 쌍둥이 다리 | 22–23 | 가·카·까 삼중 대립, 손잡은 모음(ㅘㅝㅚㅟㅢ) |
| 🏝️ 이야기 섬 | 24–26 | 문장 읽기, 연음(곰이→[고미]), 이야기 「노아의 배」 |

## 활동 13가지
손뼉 세기 · 첫소리 친구 · 글자 소개 · 가족 소개 · 원리 카드 · 듣고 고르기 · 글자 조립 · 손가락 쓰기 · 낱말 읽기 · 듣고 낱말 찾기 · 낱말 만들기 · 받침 붙이기 · 받침 미끄럼틀 · 문장 읽기 · 이야기

## 학습 장치
- 한 걸음 5~8분, 보여 주기 → 함께 → 혼자 순서
- 감점·시간제한 없음, 두 번 틀리면 정답이 반짝임(무오류 학습)
- 라이트너 상자(1·2·4·7일) 간격 반복 — 각 걸음 끝 복습 + "복습 놀이"
- 부모님 화면(덧셈 잠금): 진도표, 7일 공부 시간, 자모 40자 익힘 지도, 헷갈리는 글자, 설계 원리, 설정

## 파일
`index.html` 화면 틀 · `style.css` 디자인 · `data.js` 자모·낱말·커리큘럼 · `app.js` 활동 엔진 · `sw.js` 오프라인 · `manifest.webmanifest` 홈 화면 앱

기록은 기기의 localStorage(`joy-journey-v1`)에만 저장되며 외부로 보내지 않습니다.
